# Claude Code

This project uses Claude Code for AI-assisted development.

## About This Project

This is a TTS (Text-to-Speech) mixing project that combines different TTS systems to create a hybrid approach for optimal voice synthesis.

## Folder Structure

The workspace is organized into these primary folders:

- `1_Real_Unknown` - Objectives (OKRs), project status, and unknown problem framing.
- `2_Environment` - Setup/read files, environment docs, installation notes, and scripts.
- `3_Simulation` - UI simulations, examples, and PrismJS-related implementation notes.
- `4_Formula` - Guides, process steps, and best-practice writeups.
- `5_Symbols` - Core source code.
- `6_Semblance` - Error logs, troubleshooting docs, and solution records.
- `7_Testing_known` - Test files and validation used to prove outcomes.

## Development with Claude Code

Claude Code is used to:
- Assist with code development and refactoring
- Help with documentation
- Provide code reviews and suggestions
- Support debugging and testing

## Features

- Hybrid TTS system implementation
- Support for Kokoro TTS on Windows
- Mix strategy for combining different TTS engines

## Getting Started

Refer to `2_Environment/environment.md` for setup instructions specific to Kokoro TTS on Windows.
