# GitHub Copilot

This project uses GitHub Copilot for AI-assisted development.

## Project Context

TTS-Mix combines multiple TTS systems to deliver a hybrid voice synthesis workflow.

## Workspace Organization

- `1_Real_Unknown` - Objectives (OKRs), strategy, and unknown problem framing.
- `2_Environment` - Environment setup docs, install reports, and setup scripts.
- `3_Simulation` - UI examples and simulation-oriented implementation notes.
- `4_Formula` - Step-by-step guides and best-practice process documents.
- `5_Symbols` - Core application source code.
- `6_Semblance` - Error logs, troubleshooting records, and fixes.
- `7_Testing_known` - Tests and validation to prove outcomes.

## Folder Usage Rules

1. Start from `1_Real_Unknown` to define goals and unknowns.
2. Use `2_Environment` for prerequisites and setup.
3. Keep UI/demo examples in `3_Simulation`.
4. Store guides and procedures in `4_Formula`.
5. Keep executable code in `5_Symbols`.
6. Record issues and resolutions in `6_Semblance`.
7. Validate everything in `7_Testing_known`.
